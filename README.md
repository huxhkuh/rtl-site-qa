# RTL Site QA — בדיקת אתרים מהדפדפן

**[פתיחת הכלי](https://huxhkuh.github.io/rtl-site-qa/)** · [מצב הרצות](https://github.com/huxhkuh/rtl-site-qa/actions/workflows/qa-pages.yml)

ממשק בעברית ב־GitHub Pages, עם סריקות Playwright שרצות ב־GitHub Actions. אין צורך להפעיל שרת מקומי כדי לבדוק אתר ציבורי.

## איך מפעילים

1. פותחים את הכלי ומזינים כתובת אתר, עמודים או sitemap ומגבלת עמודים.
2. מאשרים שהאתר מורשה לבדיקה ושהדוח וצילומי המסך יהיו ציבוריים.
3. לוחצים **פתיחת בקשת סריקה ב־GitHub**. נפתחת בקשה עם כל ההגדרות מוכנות.
4. מתחברים לחשבון בעל המאגר ולוחצים **Create issue**. זו הפעולה שמתחילה את הסריקה.
5. חוזרים לכלי ורעננים את הדוחות אחרי כמה דקות. אפשר לעקוב בזמן ההמתנה דרך **מצב ההרצות**.

אין הזנה או שמירה של טוקן בדפדפן. בקשות מאנשים שאינם בעל המאגר אינן מפעילות סריקה. מומלץ להפעיל בדיקה אחת בכל פעם; GitHub שומר ריצה פעילה ובקשה ממתינה אחת בקבוצת הפרסום.

אפשר גם להפעיל דרך Actions → Scan and publish → Run workflow, ולהדביק `config_json`:

```json
{
  "baseURL": "https://your-site.example",
  "pages": ["/", "/about", "/contact"],
  "sitemap": "/sitemap.xml",
  "maxPages": 10,
  "failOn": "high"
}
```

השארת `config_json` ריק מפעילה את אתרון ההדגמה עם תקלות מכוונות. כל push ל־main מריץ את הבדיקות ואת ההדגמה ומעדכן את הממשק.

## מה מקבלים

- סריקה מוגבלת לאותו origin עם החרגות ומניעת לולאות.
- בדיקה ברוחבים 390, 768 ו־1440.
- שגיאות JavaScript, בקשות כושלות, תמונות וקישורים פנימיים שבורים.
- גלילה אופקית, רכיבים מחוץ למסך וחשדות לחיתוך טקסט.
- בדיקות בסיסיות של Tab, מיקוד, תוויות, כותרות ו־alt.
- תרחישי פעולה מפורשים ותשובות דמה לטפסים.
- דוח HTML בעברית, JSON וצילומי ראיות. תמונת ייחוס מאושרת מאפשרת השוואה חזותית; היעדרה אינו מוצג כהצלחה בהשוואה.
- סף כישלון וקודי יציאה 0, 1 ו־2. דוח מפורסם גם כאשר ממצאים מכשילים את סף האיכות.

## תרחישים והגדרות מתקדמות

בשדה JSON שבממשק אפשר להוסיף `scenarios`, `exclude`, `allowedResourceOrigins`, `maskSelectors`, `maxLinks` ו־`settleMs`. [דוגמת תפריט, FAQ וטופס](examples/fixture.config.json).

בענן מוגדרות תקרות של 30 עמודים, 300 קישורים, 10 תרחישים, 50 צעדים לתרחיש ו־20 mocks לתרחיש. כתובות מקומיות, IP ישיר, credentials בתוך URL ופורטים שאינם 80/443 אינם נתמכים. אתרים מוגני כניסה או כאלה שחוסמים את שרתי GitHub עשויים להיבדק חלקית.

בכל תרחיש ובבדיקת מקלדת בקשות הרשת חסומות, כולל GET; רק קריאות עם mock מדויק מקבלות תשובה מקומית. WebSockets ו־Service Workers חסומים. טעינת עמודים ובדיקת קישורים משתמשות ב־GET/HEAD בלבד. אין לבדוק בסביבה חיה אתר שמבצע פעולות עסקיות ב־GET; השתמשו בסביבת בדיקות והחרגות.

## דוחות ושמירת היסטוריה

20 הריצות האחרונות מוצגות באתר ונשמרות בענף `gh-pages`. גם רשימת העמודים, ממצאים, לוגים וצילומים הם מידע ציבורי. אל תסרקו דרך הממשק תוכן פרטי או פרטים אישיים. יש להוסיף מיסוך למידע שאינו בשדות טופס. היסטוריית Git עשויה לשמור גרסאות קודמות גם אחרי הסרתן מרשימת 20 הדוחות; זו אינה מחיקה מאובטחת.

ארטיפקט של כל סריקה נשמר ב־Actions למשך 30 יום, בהתאם למדיניות GitHub. דוחות עם קוד 1 או 2 עדיין מפורסמים, ולאחר הפרסום ה־workflow מסומן בהתאם לסף. כשל בהתקנה או בהגדרות עשוי לעצור את הריצה לפני יצירת דוח; במקרה כזה יש לבדוק את לוג הריצה.

לא מועלים למאגר דוחות הפרויקטים המקומיים או נתיבים מהמחשב. ההרצה הראשונה משתמשת באתרון ההדגמה בלבד.

## הפעלה מקומית ושימוש בפרויקט אחר

```sh
npm ci
npx playwright install chromium
npm test
npm run qa -- --base http://localhost:3000 --pages /,/about
```

[מדריך CLI מלא](docs/cli-guide.md). אפשר לאשר ייחוס אחרי בדיקה אנושית בפקודת `approve`, ולהוסיף את קובצי `baselines` למאגר במפורש. ייחוס לענן צריך להיווצר באותה סביבת Linux/Chromium; ייחוס מקומי מ־Windows עשוי לא להתאים. אין אישור אוטומטי לצילומים.

## הגדרת GitHub Pages במאגר נוסף

מקור הפרסום בהגדרות Pages צריך להיות **GitHub Actions**. ה־workflow מתקין Chromium, מריץ בדיקה, שומר היסטוריה בענף `gh-pages` ומפרסם דרך `actions/deploy-pages`. פרטי המאגר והממשק מתעדכנים אוטומטית בפרסום. קישורי README אלה מתייחסים להתקנה המקורית.

בדיקת האתר עצמה רצה ב־job עם הרשאת קריאה בלבד וללא credentials שמורים ב־checkout. הפרסום רץ ב־job נפרד עם הרשאות contents/pages. קלט מהבקשה נקרא כ־JSON בלבד, אינו משולב בפקודת shell ואינו מאפשר שינוי נתיבי הפלט. הקוד כולל בדיקות לסינון בקשות ולשימור היסטוריה.

## מגבלות

זוהי בדיקה אוטומטית מוגבלת ב־Chromium. קיצור טקסט מכוון, תוכן דינמי או חסימת משאב עשויים לייצר התראות שווא; תקלות ב־iframes, Shadow DOM, קורא מסך ונתיבים שלא הוגדרו עשויות לא להתגלות. יש להפעיל שיקול דעת מול הראיות. הכלי אינו הוכחה לנגישות מלאה, לאבטחה מלאה או להתאמה לנטפרי.
